# Privacy Policy — Nothing leaves your device

A self-contained, responsive privacy policy page for mobile applications. Built as a single `index.html` file with no build step, no dependencies, and no external data collection.

## Features

- **No data collection** — nothing is collected, stored, logged, tracked, or shared
- **No account required** — no personal information needed to use the app
- **No third-party trackers** — no analytics SDKs, advertising networks, or background reporting
- **Light / Dark mode** — toggle with a persistent CSS-variable theme switcher
- **Section rail navigation** — clickable dot sidebar for jumping between policy sections
- **Fully responsive** — adapts to mobile, tablet, and desktop
- **Accessible** — respects `prefers-reduced-motion`, uses semantic HTML, ARIA labels, and focus-visible outlines

## Usage

Open `index.html` in any modern web browser. No server or build step is required.

## Customization

Edit the contact email, last-updated date, and section text directly in `index.html`. All styling is contained in the embedded `<style>` block; all interactivity is in the embedded `<script>` block.
